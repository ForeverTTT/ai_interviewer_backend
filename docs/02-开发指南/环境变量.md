# 环境变量

> 状态：现行 · 最后核对：2026-10-01

本文是前后端环境变量的唯一权威清单，依据是代码中 `process.env.*` 和 `import.meta.env.*` 的实际读取情况。模板文件分别是 `backend/.env.example` 和 `frontend/.env.example`。

**敏感**表示泄露后会造成安全风险：只能放在本地 `.env`、Cloud Run 环境变量或 Secret Manager 里，不能提交到 Git，也不能写进任何 `VITE_*` 变量。

## 后端（`backend/.env`）

### 必填

| 变量 | 默认值 | 敏感 | 说明 |
|---|---|:---:|---|
| `SUPABASE_URL` | 无 | | Supabase 项目地址。缺失时服务仍会启动，但会打印警告，所有数据库功能不可用 |
| `SUPABASE_SERVICE_ROLE_KEY` | 无 | ✅ | Service Role 密钥，后端用它绕过 RLS 读写数据，并校验用户 JWT |
| `GEMINI_API_KEY` | 无 | ✅ | Google AI Studio 密钥，用于文本面试、练习、报告、简历工具和 Gemini Live。未设置时文本调用会改走 Vertex AI（见下方"Vertex AI"），但 Live 语音必须使用它 |

### 服务

| 变量 | 默认值 | 敏感 | 说明 |
|---|---|:---:|---|
| `PORT` | `5000` | | 监听端口。Docker 镜像默认 `8080`，Cloud Run 会自动注入 |
| `FRONTEND_URL` | `http://localhost:3000` | | 加入 CORS 和 WebSocket Origin 允许列表的前端地址，可用逗号分隔多个；生产环境设为 `https://global.flowlab-career.com,https://aiinterviewer-491711-7b1cf.web.app`（旧地址保留到用户迁移完）。本地常用端口（3000、3001、5173）始终被允许 |

### Gemini 模型

| 变量 | 默认值 | 说明 |
|---|---|---|
| `GEMINI_MODEL` | `gemini-3.7-flash` | 文本主模型：报告、简历工具，以及兼容通道的 LangGraph |
| `GEMINI_FALLBACK_MODEL` | `gemini-3.5-flash-lite` | 兼容旧配置：未设置复数列表时，作为第一个候选，其后追加默认候选并去重 |
| `GEMINI_FALLBACK_MODELS` | `gemini-3.5-flash-lite,gemini-3.1-flash-lite,gemini-3.5-flash,gemini-3.6-flash,gemini-3.7-flash` | 通用文本兜底顺序（包括练习模型；报告使用独立列表）；去除重复和当前主模型，每个候选最多尝试一次。显式空字符串禁用通用兜底。限流、暂时不可用、模型 404、网络故障或单模型超时才切换；400/401/402/403 不切换。不是 Live 音频模型列表 |
| `GEMINI_MODEL_TIMEOUT_MS` | `12000` | 公共文本调用层单模型超时；仍受调用者总预算约束（练习出题 15 秒，其余默认 45 秒），不会因增加模型而无限延长 |
| `GEMINI_REPORT_TIMEOUT_MS` | `90000` | 报告的模型调用总预算，包含日志回调、模型尝试及退避等待；最多 90 秒，为 120 秒生成锁预留 30 秒解析与存储余量 |
| `GEMINI_REPORT_MODEL_TIMEOUT_MS` | `30000` | 报告单模型等待时间，覆盖通用单模型配置，并受报告总预算约束 |
| `GEMINI_REPORT_FALLBACK_MODELS` | `gemini-3.1-flash-lite,gemini-3.5-flash-lite` | 报告专用备用顺序，不改变主模型；独立于通用备用列表，显式空字符串禁用。切换前等待约 1、2 秒并添加随机抖动，等待受总预算取消保护 |
| `GEMINI_PRACTICE_MODEL` | `gemini-3.5-flash-lite` | 练习模式的出题、反馈和提示 |
| `GEMINI_LIVE_MODEL` | `gemini-3.1-flash-live-preview` | Gemini Live 实时语音模型 |
| `GEMINI_LIVE_VOICE` | `Kore` | Live 默认音色；同时作为英语音色的后备值 |
| `GEMINI_LIVE_VOICE_EN` / `_DE` / `_ZH` | 未设置 | 按面试语言覆盖 Live 音色 |

### 语音合成（TTS）

以下变量只用于兼容通道的 `/api/chat/tts`、`/tts-stream`。当前面试的声音由 Gemini Live 生成，使用上面的 `GEMINI_LIVE_*` 变量。

| 变量 | 默认值 | 敏感 | 说明 |
|---|---|:---:|---|
| `GEMINI_TTS_MODEL` | `gemini-2.5-flash-preview-tts` | | TTS 模型 |
| `GEMINI_TTS_KEYS` | 回退到 `GEMINI_API_KEY` | ✅ | 多个 API Key 用英文逗号分隔，用于轮换配额 |
| `GEMINI_TTS_VOICE_EN` / `_DE` / `_ZH` | 由面试官风格和语言决定 | | 设置后，该语言的所有风格都使用这个音色 |

### Vertex AI（可选后备）

用于两种情况，运行环境都需要有 Application Default Credentials：

- **文本调用**：只在没有设置 `GEMINI_API_KEY` 时改走 Vertex AI。
- **TTS**：只要显式设置了 `GCP_PROJECT_ID` 或 `GOOGLE_CLOUD_PROJECT`，`/api/chat/tts` 和 `/api/chat/tts-stream` 就会**优先**调用 Google Cloud TTS，失败后才回到 Gemini TTS。TTS 判断时不使用代码里写死的默认项目。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `GCP_PROJECT_ID` | 回退到 `GOOGLE_CLOUD_PROJECT`，再回退到代码中写死的 `aiinterviewer-491711-7b1cf` | Vertex AI 项目，优先级高于 `GOOGLE_CLOUD_PROJECT` |
| `GOOGLE_CLOUD_PROJECT` | 无 | 同上 |
| `GCP_LOCATION` | `us-central1` | Vertex AI 区域 |
| `GCP_MODEL` | `gemini-3.7-flash` | 走 Vertex 时使用的文本模型 |
| `GCP_TTS_VOICE_TIER` | `Studio` | Google Cloud TTS 音色层级 |

在 GitHub `production` Environment 配置；本地手动运行脚本时可放入未跟踪的 `backend/.env`。详细启用流程见[反馈邮件提醒](../05-运维/反馈邮件提醒.md)。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `RESEND_API_KEY` | 无 | 发信 API Key，敏感；只在实际发送时需要 |
| `FEEDBACK_DIGEST_TO` | 无 | 单个收件邮箱，存为 Secret |
| `FEEDBACK_DIGEST_FROM` | 无 | 已验证域名的发件地址，可带显示名称 |
| `FEEDBACK_DIGEST_DASHBOARD_URL` | 当前云端 Supabase 项目的 Table Editor URL | 可选 HTTPS 查看入口；本地数据库需显式配置 |

## 前端（`frontend/.env`）

`VITE_*` 变量会在构建时**编译进浏览器代码**，任何人都能看到，所以只能填写可公开的值。

| 变量 | 必填 | 默认值 | 说明 |
|---|:---:|---|---|
| `VITE_SUPABASE_URL` | ✅ | 无 | Supabase 项目地址 |
| `VITE_SUPABASE_ANON_KEY` | ✅ | 无 | Supabase 公开的 Anon Key，安全性由 RLS 保证。**绝不能填 Service Role Key** |
| `VITE_API_URL` | | 无 | 后端地址，**优先级高于 `VITE_BACKEND_URL`**。生产环境使用这个变量 |
| `VITE_BACKEND_URL` | | 见下方 | 后端地址，本地开发填 `http://localhost:5000` |
| `VITE_LOCAL_SUPABASE` | | `false` | 为 `true` 时登录页只显示本地账户登录 |
| `VITE_LOCAL_EMAIL` | | `local@example.com` | 本地开发账户邮箱 |
| `VITE_LOCAL_PASSWORD` | | `localdev123` | 本地开发账户密码 |
| `VITE_APP_VERSION` | | `dev` | 写进每条前端埋点的版本号。CI 构建时自动注入：正式部署为 commit SHA，PR 预览为 `preview-<SHA>`，本地不用设置 |

两个后端地址变量都没有设置时（`src/lib/backendBase.js`）：

- 在 `localhost` / `127.0.0.1` 上访问时，使用 `http://localhost:5000`；
- 在其他域名上访问时，使用代码中写死的生产 Cloud Run 地址。

### 生产配置

`frontend/.env.production` 已提交到仓库，包含生产环境的 `VITE_API_URL`、Supabase URL 和 Anon Key（都是公开值），CI 构建时会自动使用。修改它就等于修改线上配置。

### 模板中已不再使用的变量

`frontend/.env.example` 中的 `VITE_RPM_AVATAR_EN`、`VITE_RPM_AVATAR_DE`（Ready Player Me 模型）目前没有被任何代码读取。
