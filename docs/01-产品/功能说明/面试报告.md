# 面试报告

> 状态：现行 · 最后核对：2026-10-01 · 入口：`/interview/:id/report`（成长中心、面试结束提示） · 技术文档：[面试报告](../../03-技术与架构/面试报告.md)

每场面试结束后生成一份报告。面试结束后，报告**只根据这场面试的对话**生成。

## 1. 报告结构

| 部分 | 内容 |
|---|---|
| 评估摘要 | 总体评价、优势与亮点、改进方向（每条都附原因和建议） |
| 五维面试准备度 | 技术能力、经历与证据深度、结构化表达、沟通与协作、面试策略与岗位匹配。每个分数都附有本场的原话证据，可以展开查看 |
| 下一道最值得练的题 | 从本场弱项中挑出一道题，附原因和预计用时，可以直接"开始针对练习" |
| 逐题复习 | 两种视图：**单题卡**（一次一题，先自己回想，再翻开参考答案和差距）和**所有题总览** |
| 逐题对比 | 左边是你的实际回答，右边是同类问题的参考样例，下方列出主要差距和改进建议 |
| 完整对话记录 | 放在最下方，每条对话可以展开解析、改进点和参考标答 |

### 两种模式的侧重点

- **正式模式**：结束后对整场表现做一次评价。
- **练习模式**：侧重首次回答和最新回答之间的进步、提示的使用情况和能力成长。

## 2. 准备度的规则

- 分数只表示**本场报告中可以验证的表现**，不代表拿到 Offer 的概率。
- 没有足够证据的维度显示"证据不足"，不会凭空打分。
- 只有一份报告时标记为"初始评估"；同一维度至少有两份报告评分后，才显示趋势。
- 成长中心的"职场胜算"汇总的就是这些报告中的准备度，见[成长中心](成长中心.md#2-职场胜算)。

## 3. 从报告中继续

- **收藏本题**：每道题都可以单独收藏到[题目收藏](题目收藏.md)，再点一次取消。不支持收藏整份报告。
- **开始针对练习**：用推荐的题目新建一场练习，消耗 300 能量值。

## 4. 语言

- 报告按**界面语言**显示。切换界面语言后，报告会自动翻译成新的语言（只翻译分析部分，第一次切换需要稍等），不扣能量值。
- 面试中的原始问答保持面试语言。

## 5. 页面状态

| 情况 | 表现 |
|---|---|
| 报告生成中 | 显示"正在生成面试报告"，通常需要几秒到一分钟 |
| 生成失败或没有报告 | 说明可能的原因；如果有保存的对话，提供"重新生成报告"按钮 |
| 没有保存的对话 | 显示"暂无保存的对话内容"，无法生成报告 |
| 加载失败 | 显示"无法加载该记录"，并提供返回成长中心的入口 |
| 推荐练习创建失败 | 提示检查能量值余额后重试 |

重新生成报告会覆盖原来的报告，不扣能量值。
