# 简历优化

> 状态：现行 · 最后核对：2026-10-01 · 入口：`/resume-tailor`（侧栏"简历优化"） · 技术文档：[简历优化](../../03-技术与架构/简历优化.md)

针对某一个具体岗位，把默认简历改成"对齐这份 JD"的版本，并生成配套的求职信。

## 1. 准备输入

| 输入 | 来源 | 规则 |
|---|---|---|
| 基础简历 | 自动读取[个人资料](个人资料与简历.md)中的简历 | 个人资料里没有简历时，可以在这里上传 PDF，解析后会**保存到个人资料** |
| 目标职位描述 | 用户粘贴 | 至少 50 个字符 |
| 目标职位 | 粘贴 JD 后自动识别，可以修改 | 必填 |
| 输出语言 | 跟随简历 / 英语 / 德语 | |

职位识别在浏览器本地完成，不扣费。

## 2. 按 JD 优化简历

点击"匹配关键词并优化"，消耗 **100 能量值**。

**核心承诺：只优化已有的事实和措辞，不编造经历、技能、雇主、日期或数据。**

| 结果 | 说明 |
|---|---|
| AI 定向简历 | 完整的优化版简历，可以直接编辑 |
| 已匹配关键词 | JD 要求、简历中也有证据的关键词 |
| 尚无证据的关键词 | JD 要求、但简历中没有证据的关键词。**不会被强行写进简历**，提示用户自己补充真实经历 |
| 本次重点修改 | 说明改了哪些地方、为什么改 |

- **保存为个人简历**：用优化后的版本替换个人资料中的默认简历。不保存的话，离开页面后结果会丢失。
- 可以复制，或导出为 Word / PDF。

## 3. 求职信

点击"生成求职信"，消耗 **100 能量值**。

- 优先使用上方**优化后的简历**；还没优化时使用基础简历。同时结合完整的 JD。
- 篇幅约 300 词。输出语言选"跟随简历"时，求职信使用英语。
- 生成的求职信可以编辑、复制，或导出为 Word / PDF。

面试配置页也可以生成求职信，那里可以选择篇幅（100 / 200 / 300 词）和语言。

## 4. 页面状态

| 情况 | 表现 |
|---|---|
| 没有基础简历，或 JD 不足 50 字 | "请先准备基础简历，并粘贴至少 50 个字符的职位描述" |
| 能量值不足 | "能量值不足，当前操作需要 100 能量" |
| 生成失败 | 提示稍后重试，不扣费 |
| 职位识别失败 | 提示手动填写职位 |
