# 优势测试

> 状态：现行（解读文案为占位内容） · 最后核对：2026-10-01 · 入口：`/gallup`（侧栏"优势测试"） · 技术文档：[优势测试](../../03-技术与架构/优势测试.md)

一份 20 题的盖洛普风格测评，帮助用户找到自己的优势领域，用来准备"你最大的优势是什么"这类问题。

## 1. 测评流程

```text
开始优势测评 → 逐题作答（可以上一题 / 下一题）→ 提交测试（消耗 100 能量值）→ 查看结果
```

- 每题按 5 级打分：非常不同意 / 不同意 / 一般 / 同意 / 非常同意。第一次选择后自动跳到下一题；回到之前的题目可以修改答案。
- 进度**实时保存**，中途离开后可以"继续测试"。保存进度不扣费。

## 2. 结果

覆盖四大领域：

| 领域 | 含义 |
|---|---|
| 执行力 | 把想法付诸实践，关注结果和过程的精确性 |
| 影响力 | 推销想法、主导局面、激励他人 |
| 关系建立 | 维系关系，营造协作氛围 |
| 战略思维 | 分析信息，看清方向，做出判断 |

- **得分**：每个领域 0–100 分，等于该领域各题得分之和占满分的比例。按得分从高到低排列，并用雷达图展示。
- **档位**：≥75 为高，40–74 为中，<40 为低。每个领域按档位显示解读：核心特征、职场行为表现、领导力风格、潜在短板盲区、高阶提升策略。
- 每个领域还附有适合的职业方向和面试建议。
- 解读支持中、英、德三种语言，跟随界面语言切换。

## 3. 规则

- 每个用户只保留一份结果。目前界面上**没有重新测试的入口**（虽然有"重新开始 / 重新测试"的文案，但没有对应按钮）。
- 没有回答的题按"一般"（3 分）计算。
- 余额不足时回到答题页并提示，进度不受影响。
- 解读加载失败时，仍然显示四个领域的得分，只是没有解读文字。

## 4. 已知限制

- 解读文案目前是统一生成的占位内容，尚未经过专业审校。
- 结果暂时不会自动用于模拟面试或简历诊断。
