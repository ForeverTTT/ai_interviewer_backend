# 功能说明

> 状态：现行 · 最后核对：2026-10-01

本目录从**用户视角**说明每个功能：入口、流程、业务规则、页面状态、计费和边界情况。跨模块共用的规则（登录、能量值、多语言、页面状态、主题）写在[通用规则](../通用规则.md)，实现方式写在 [03-技术与架构](../../03-技术与架构/)。

## 写法约定

- 每篇开头写状态、最后核对日期、入口和对应的技术文档。
- 二级标题对应子功能，每个子功能按需写：**入口与前置条件、规则、页面状态、计费、边界情况**，没有的就省略。
- 规则（阈值、次数、扣费）以这里为准，技术文档只说明如何实现并链接回来。
- 不写文件路径、表名和接口路径；界面文案以 `frontend/src/locales/*.json` 为准，不整段抄进来。
- 只写**已上线**的功能。规划中的功能写进 [06-决策与方案](../../06-决策与方案/)，界面上没有入口的后端能力不写。
- 发现界面文案和实际行为不一致时，在对应文档中单独列出，并登记到[问题与想法](../../问题与想法.md)。
- 一篇超过约 300 行，或者某个子功能有了独立的发展节奏时，再拆成单独一篇。
