# 面试配置

> 状态：现行 · 最后核对：2026-10-01 · 入口：`/setup`（侧栏"开始面试"） · 技术文档：[面试配置](../../03-技术与架构/面试配置.md)

用户在这里描述"要面试什么岗位、想怎么练"，然后开始一场面试。

## 1. 岗位信息

| 项目 | 必填 | 规则 |
|---|:---:|---|
| 职位描述（JD） | ✅ | 至少 50 个字符。建议从招聘官网完整复制，细节越多，追问越贴合 |
| 应聘职位 | ✅ | 可以手写，也可以由系统从 JD 中识别 |
| 职位类型、类别 | | 可选；选择类别后会出现细分职位，方便快速选择 |

- **自动识别**：粘贴 JD 后，系统自动识别雇佣类型（实习 / 全职 / 学生工 / 兼职 / 合同制）、行业类别和职位名称，结果可以手动修改，也可以"重新识别"。识别在浏览器本地完成，不扣能量值。
- **JD 历史**：本机保存最近 10 条用过的 JD，可以一键再次使用、删除或清空。只保存在当前浏览器中。

## 2. 简历（可选）

- 默认自动使用**个人资料中保存的简历**；只有个人资料里还没有简历时，才需要在这里上传 PDF。
- 在这里上传的 PDF 解析后会同时保存到个人资料。
- 不使用简历也可以开始，但面试官就不会围绕简历追问。
- 页面会明确显示本场用的是哪份简历：本场上传的、个人资料里的，还是没有使用简历。
- 创建面试时会保存一份简历快照，之后修改简历不会影响这场面试。

## 3. 面试设置

| 设置 | 选项 | 说明 |
|---|---|---|
| 面试类型 | HR / 招聘面试官、技术面试官、综合面试官 | 决定考察方向：HR 面考察沟通、动机、经历与 STAR；技术面考察岗位知识、项目实战、算法与系统设计；综合面两者平衡。建议时长：HR 10 分钟，技术 15–20 分钟，综合 10–15 分钟 |
| 面试官性格 | 专业严谨、温和鼓励、严厉压力、深度分析 | 只改变互动方式和追问力度，**不改变评分标准**；也会影响面试官的声音 |
| 面试模式 | 练习模式、正式模式 | 见下表 |
| 难度 | 简单、中等、困难、自适应 | 自适应从中等开始，根据上一题的表现自动升降 |
| 面试语言 | English、Deutsch、中文 | 与界面语言无关 |
| 面试时长 | 5–60 分钟，每档 5 分钟 | 只对正式模式有效 |

### 两种模式

| | 练习模式 | 正式模式 |
|---|---|---|
| 目的 | 学习和打磨回答 | 模拟真实面试 |
| 时长 | **不限时** | 按所选时长连续计时 |
| 题量 | 由难度决定：简单 6 题、中等或自适应 10 题、困难 19 题（都包含 1 道开场自我介绍） | 按时长自动安排 |
| 中途反馈 | 每题立即给出 | 结束前不显示 |
| 提示、重答、笔记、暂停 | 可以 | 不可以 |

详细规则见[模拟面试](模拟面试.md)。

## 4. 开始面试

- 右侧"面试配置总览"实时汇总所有选择。
- 点击"开始模拟面试"后扣除 **300 能量值**，进入面试房间（`/interview/:id`）。
- 网络不稳定时会自动重试一次；重复提交不会创建两场面试，也不会重复扣费。
- 配置在创建后就固定下来，面试中途不能修改面试类型、难度或语言。

## 5. 页面状态

| 情况 | 表现 |
|---|---|
| 职位或 JD 没填、JD 不足 50 字 | 在对应输入框下提示，并自动滚动到第一个错误 |
| 能量值不足 | 顶部提示"能量值不足"，不会创建面试 |
| 登录失效 | 提示"登录状态已失效"，并提供重新登录按钮 |
| 创建失败 | 提示"暂时无法创建面试，请稍后重试"，已填写的内容保留 |
| PDF 问题 | 按[通用规则](../通用规则.md#4-页面状态)中的上传规则提示 |

## 6. 其他入口

- 从成长中心的 Offer 冲刺任务进入时，岗位、JD、面试类型、模式和时长会**预先填好**。
- 这个页面还提供求职信生成，功能与[简历优化 · 求职信](简历优化.md#3-求职信)相同。
