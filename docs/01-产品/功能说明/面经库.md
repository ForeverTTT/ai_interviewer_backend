# 面经库

> 状态：现行 · 最后核对：2026-10-01 · 入口：`/experiences`（侧栏"面经库"）、`/experiences?mine=true`（"我的面经"） · 技术文档：[面经库](../../03-技术与架构/面经库.md)

在德留学生分享的真实面试经历，覆盖企业、初创公司和高校。

## 1. 浏览

- **不需要登录**。未登录时使用官网布局，登录后显示在侧栏工作台中。
- 顶部显示面经总数。
- **筛选**：全部 / 实习与学生工 / 高校录取 / 我的面经。
- **搜索**：公司、岗位、题目、心得。
- 每张卡片显示公司、岗位、地点、日期和结果，"展开详情"后可以看到每轮的形式、时长、面试真题，以及心得与小贴士。

## 2. 分享面经

需要登录。

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 类型 | ✅ | 工作 / 学校 |
| 公司或学校名称 | ✅ | |
| 岗位或项目方向 | ✅ | |
| 时间 | ✅ | 年和月 |
| 地点、部门、语言 | | |
| 面试轮次 | | 可以添加多轮：形式（如技术面、HR 面）、时长、面试真题（可以添加多道） |
| 结果 | | 拿到 Offer / 未通过 / 录取 / 通过 |
| 薪资 | | |
| 心得体会 | | |

规则：

- 每个用户**每天最多分享 1 篇**；超过时提示"您今天已经分享过面经了，请明天再来吧"。
- 发布成功后奖励 **+200 能量值**。
- 发布时选择**发布身份**：「用我的昵称」（默认）或「匿名」（显示为「匿名荷包蛋」）。没设昵称的用户可以在表单里当场设置，也可以选匿名。
- 昵称在个人资料页顶部设置，2–20 个字，全站唯一（不区分大小写），不能是邮箱、网址或手机号，也不能用「匿名荷包蛋」「管理员」「FlowLab」等保留名。
- 用昵称发布的面经显示作者**当前**的昵称，改昵称后旧面经跟着变。上线前发布的面经保持原来的署名（真实姓名或邮箱前缀），作者设了昵称后改为显示昵称。
- 从飞书导入的面经一律显示「匿名荷包蛋」。

## 3. 我的面经

- 查看和管理自己发布的面经。
- **删除**需要二次确认；删除后会**扣回 200 能量值**（余额最低扣到 0）。

## 4. 面经的其他用途

用户分享的面经会作为参考素材，用于练习模式的出题：系统会挑选与目标岗位相关的面经，让题目更贴近真实面试。

## 5. 界面说法与实际行为不一致

以下界面文案与目前的实际行为不符，需要修改文案或补上对应的功能：
