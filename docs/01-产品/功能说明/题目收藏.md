# 题目收藏

> 状态：现行 · 最后核对：2026-10-01 · 入口：`/notes`（侧栏"题目收藏"、成长中心"查看全部"） · 技术文档：[题目收藏](../../03-技术与架构/题目收藏.md)

把练习和面试报告中值得复习的题目集中成卡片，用来复盘和针对性再练。

## 1. 卡片从哪里来

| 来源 | 怎么产生 |
|---|---|
| 练习 | 在练习模式中为某道题写私人笔记时，自动生成或更新这道题的卡片 |
| 面试报告 | 在报告的逐题复习中点击"收藏本题" |

- 同一道原题只会有一张卡片，重复收藏不会产生重复卡片。
- 卡片保存的是收藏时的**快照**：原题、你的回答、反馈、职位、语言、面试官类型。之后原面试有变化，卡片内容不变。
- 不支持收藏整份报告。

## 2. 卡片能做什么

| 操作 | 说明 |
|---|---|
| 显示 / 收起回答 | 默认隐藏你的回答和反馈，方便先自己回想 |
| 私人笔记、标签 | 标签用英文逗号分隔，点击"保存笔记与标签" |
| 复习状态 | 待复习 ↔ 已复习，新卡片默认为待复习 |
| 置顶 | 置顶的卡片会出现在冲刺计划最后 48 小时的检查清单中 |
| 再练一次 | 用这道题新建一场练习（10 分钟、中等难度），消耗 300 能量值；不会改动原来那场面试 |
| 查看原始内容 | 跳回卡片来源的面试或报告 |
| 取消收藏 | 删除卡片 |

## 3. 浏览与筛选

- **两种视图**：闪卡视图（一次一张，可以上一张 / 下一张）和列表视图。
- **搜索**：问题、回答、反馈、笔记、职位、标签。
- **筛选**：职位、来源（练习 / 面试报告）、面试官（综合 / 技术 / 行为 HR）、标签、复习状态、日期范围；可以一键重置。

## 4. 页面状态

| 情况 | 表现 |
|---|---|
| 没有卡片或筛选后没有结果 | "暂时没有匹配的题目卡片"，说明卡片的两种来源 |
| 加载、保存、取消收藏失败 | 对应的错误提示，可以重试 |
| 再练一次失败 | 提示检查能量值余额 |

## 5. 和成长中心的关系

成长中心只显示最近 3 张待复习卡片；完整的收藏库在这个页面。写笔记、复习卡片**不计入**有效训练。
