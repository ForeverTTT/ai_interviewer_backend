# 个人资料与简历

> 状态：现行 · 最后核对：2026-10-01 · 入口：`/profile`（查看）、`/profile/edit`（编辑），侧栏"个人资料" · 技术文档：[个人资料与简历](../../03-技术与架构/个人资料与简历.md)

这里保存一份"默认简历"。模拟面试、简历优化和求职信都会自动使用这份简历。

## 1. 页面构成

| 页面 | 内容 |
|---|---|
| 查看页 `/profile` | 头像、求职状态、能量值余额与用途、结构化简历展示、简历诊断报告 |
| 编辑页 `/profile/edit` | 上传和解析 PDF、编辑结构化资料、编辑面试用简历原文、生成简历诊断、选择头像 |

## 2. 简历的两种形式

| 形式 | 用途 |
|---|---|
| **结构化资料** | 个人信息、个人简介、工作经历、教育、项目、发表、技能、语言、奖项，分模块填写 |
| **面试用简历原文** | 一段纯文本，是面试官追问、简历诊断和简历优化真正读取的内容 |

保存结构化资料后，系统会自动生成面试用的简历原文；也可以直接编辑原文。

## 3. 上传与解析

```text
上传 PDF → 提取正文（可以校对、编辑）→「AI 解析到表单」→ 检查表单 → 保存
```

- **提取正文**：不扣费。只提取文本，不会自动保存，需要用户确认。
- **AI 解析到表单**：消耗 **50 能量值**，把正文拆分到结构化资料的各个模块。至少需要约 80 个字的文本。解析结果只是填进表单，需要检查后手动保存。
- PDF 的各种问题（扫描件、加密、过大）按[通用规则](../通用规则.md#4-页面状态)提示。

## 4. 简历诊断

可以选填目标岗位或方向，然后点击"生成诊断报告"，消耗 **200 能量值**。需要至少约 80 个字的简历原文。

| 部分 | 内容 |
|---|---|
| 总体评价 | |
| 维度评分（1–10） | 综合、清晰度、成果影响力、结构逻辑、关键词 / ATS，以及专业度 |
| 宏观建议 | 从整体看：信息密度、经历与目标岗位的匹配、成果是否一眼可见 |
| 亮点与优势 | |
| 优先改进（高影响） | 2–4 条，每条有问题、建议做法和改写示例 |
| 分模块深挖 | 按 STAR 打磨工作和项目经历，给出"修改前 / 修改后"对照；技能列表一般不需要大改 |
| 定位与求职市场 | |
| 按优先级执行的清单 | 每项附预期效果 |

- 改写示例保持简历原来的语言；其他说明按界面语言显示。切换界面语言时自动翻译，不扣费。
- 诊断保存在账户里，刷新后仍然在。重新生成会覆盖之前的报告。
- 生成过程中提示"请不要离开此页面"。

## 5. 其他资料

| 项目 | 说明 |
|---|---|
| 头像 | 5 个预设头像任选一个，或上传图片（最大 2 MB） |
| 求职状态 | 积极求职中 / 已入职、停止求职 |
| 能量值 | 显示余额，以及各功能的消耗：模拟面试 300、简历诊断 200、简历解析 50；"获取更多能量"打开引导弹窗，见[通用规则 · 能量值](../通用规则.md#2-能量值) |
