# 模拟面试

> 状态：现行 · 最后核对：2026-10-01 · 入口：`/interview/:id`（由[面试配置](面试配置.md)创建，或从成长中心继续） · 技术文档：[模拟面试](../../03-技术与架构/模拟面试/面试流程.md)（含[面试房间](../../03-技术与架构/模拟面试/面试房间.md)、[实时语音与TTS](../../03-技术与架构/模拟面试/实时语音与TTS.md)、[agent与Prompt](../../03-技术与架构/模拟面试/agent与Prompt.md)）

面试在一个全屏的"数字面试房间"中进行：左边是面试官画面和你的摄像头小窗，右边是对话栏，界面类似线上视频面试。

## 1. 进入面试房间

1. **会前准备**：可以预览摄像头（可选背景：无 / 模糊 / 自然 / 办公室），授权麦克风并查看音量。摄像头不是必需的。
2. 点击"进入面试间"，系统连接语音服务，然后面试官主动开场，第一题是自我介绍。
3. 每一场面试都有自己的链接，刷新或稍后再打开同一个链接，进入的都是同一场面试。

浏览器不支持摄像头或麦克风（需要 HTTPS 或 localhost），或者用户拒绝授权时，页面会给出提示，并且仍然可以打字作答。

## 2. 作答方式

- **语音**：面试官用语音提问，系统把你的回答实时转写成文字。
- **文字**：随时可以直接打字，按 Enter 发送。
- **面试官语音**可以在输入栏右侧的喇叭图标开关。
- 面试官的声音由面试语言和面试官性格决定。

## 3. 正式模式

模拟真实面试，一场连续进行到底。

| 规则 | 说明 |
|---|---|
| 计时 | 进入后按所选时长倒计时，时间以服务器为准，刷新页面不会重置；最后 1 分钟会有提醒 |
| 中途反馈 | 不显示任何评分或点评 |
| 不允许 | 暂停、提示、重答、笔记 |
| 时间到 | 如果你正在回答，可以把这一题答完，提交后面试自动结束；不会再出新题 |
| 主动结束 | 点击"结束"并确认 |
| 离开或关闭页面 | **视为结束面试**，系统会用已经保存的对话生成报告；之后不能回到这场面试继续 |

## 4. 练习模式

以学习为目的，每一步都由你自己控制，AI 不会在你停顿时插话，也不会自动跳到下一题。

### 4.1 一道题的流程

```text
面试官朗读题目 → 你语音或打字作答（答案可以编辑）→ 提交
  → 立即得到得分（0–100）和反馈 → 可以：看提示 / 写笔记 / 重答
  → 选择"已掌握 → 下一题"或"跳过 → 下一题"
```

| 规则 | 说明 |
|---|---|
| 停止录音 | 不会自动提交，可以先修改转写的文字再提交 |
| 重答 | 提交后要先点"重答这道题"，才能提交新的版本；每次回答都会保留，不会覆盖之前的回答 |
| 提示 | 一层一层开放，共四层：思路方向 → 回答结构 → 关键要点 → 参考示例；四层用完后按钮锁定 |
| 已掌握 | 必须至少回答过一次才能标记 |
| 跳过 | 可以填写跳过原因（可选） |
| 私人笔记 | 每道题都可以写，笔记会自动出现在[题目收藏](题目收藏.md)中 |
| 朗读题目 | 可以让面试官再读一遍 |
| 下一题 | 会参考你最近几题的回答和反馈来出题；自适应难度下，得分 ≥85 升一级、≤55 降一级 |

### 4.2 暂停与时长

- 练习**不限时**，可以随时暂停；暂停时题目、回答、提示和笔记都会保存。
- 离开页面会自动暂停；回来后保持暂停状态，点击"继续"才会恢复计时。
- 页面显示"第 x/y 题 · 难度 · 类型"。完成全部题目后，自动生成练习总结报告。

### 4.3 出题失败

新题生成太慢（超过 15 秒）或失败时，系统会换一道符合当前阶段的备用题；如果仍然失败，会显示可以重试的错误，不会一直卡在加载。

## 5. 断线与恢复

| 情况 | 结果 |
|---|---|
| 刷新页面 | 回到同一场面试：练习恢复到当前题，以及所有回答、提示、笔记和计时；正式模式按服务器时间继续 |
| 语音连接中断 | 对话栏顶部显示错误提示和重试按钮，点击后重新连接，只恢复这一场面试的必要上下文（不会自动重连） |
| 同时在两个标签页打开不同的面试 | 互不干扰 |
| 同一场面试在两个地方同时操作 | 后提交的一方会被拒绝，需要刷新后继续 |
| 网络重试 | 不会重复提交答案、重复出题或重复扣费 |

## 6. 结束之后

点击结束后，页面提示"报告正在生成"。用户可以：

- 留在这里等待；
- 前往成长中心，报告生成后会出现在那里；
- 生成失败时点击"重试生成"，已保存的对话不会丢失。

报告内容见[面试报告](面试报告.md)。

## 7. 计费

进入面试不再扣费，300 能量值已在创建时扣除。面试中的语音、对话和报告生成都不额外收费。
