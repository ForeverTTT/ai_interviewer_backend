# 成长中心

> 状态：现行（付费分层未上线） · 最后核对：2026-10-01 · 入口：`/dashboard`（侧栏"成长中心"） · 技术文档：[成长中心](../../03-技术与架构/成长中心.md) · 设计方案：[成长中心改版方案](../../06-决策与方案/进行中/成长中心改版方案.md)

成长中心按"**行动 → 结果 → 复盘**"组织：打开页面先看到今天最值得做的一件事，再看最近的结果和历史记录。

## 1. Offer 冲刺计划

放在页面最上方。

### 1.1 设定目标

| 项目                            | 必填 | 说明                                                     |
| ------------------------------- | :--: | -------------------------------------------------------- |
| 目标职位                        |      |                                                          |
| 目标 JD                         |      |                                                          |
| 下一次面试日期、目标 Offer 日期 |      | 用来计算倒计时和冲刺阶段                                 |
| 面试官类型                      |      | HR / 技术 / 综合，默认综合                               |
| 每周训练天数                    |      | 3、5 或 7 天，默认 5 天                                  |
| 提醒方式                        |      | 站内提醒（默认开启）、浏览器通知、周报；邮件提醒尚未开放 |

每个用户只有一个计划，可以修改或删除；删除计划时，任务和提醒一起删除。

### 1.2 冲刺阶段

根据距离面试的天数，计划会自动切换阶段，每周的任务也随之变化：

| 阶段         | 距离面试                  | 重点                                          |
| ------------ | ------------------------- | --------------------------------------------- |
| 打基础       | 21 天以上，或没有设置日期 | 建立基线，完成第一次正式模拟                  |
| 聚焦         | 8–21 天                  | 针对弱项反复练习                              |
| 临近         | 3–7 天                   | 正式模拟、复习收藏题                          |
| 最后 48 小时 | 2 天内                    | 面试前检查清单，附最近 3 张置顶或待复习的题卡 |
| 面试当天     | 当天                      | 当天准备                                      |
| 已过期       | 目标日期已过              | 提示更新目标                                  |

### 1.3 任务

- **今天只做这一件事**：首屏只展示一个最高价值的任务，附预计用时（3–60 分钟）和原因。
- **本周任务**：每周最多 5 个（每周 3 天的计划最多 3 个），其余默认折叠，不会越积越多。
- 每个任务都有来源依据，例如来自某份报告的弱项题、某张待复习的收藏卡。
- 点击任务后：针对性题目会直接新建一场练习（消耗 300 能量值）；基线或正式模拟任务会进入预先填好的面试配置页。
- 任务可以标记完成或跳过。跳过或过期的任务不能再修改。

### 1.4 提醒与里程碑

- 面试前 7 天、前 2 天和当天，以及每周，会发送提醒（按用户选择的渠道）。浏览器通知只会在用户主动点击时请求权限。
- **里程碑**：首份正式报告、连续 5 天有效训练、某个维度提升至少 15 分。

## 2. 职场胜算

- 汇总最近面试报告中的**五维准备度**：技术、经历证据、结构表达、沟通协作、策略匹配。
- 只采用报告中有证据的评分，不根据资料完整度、练习次数等推算。
- 计算时参考最近 5 份报告，越新的报告、职位越相似、面试官类型相同的报告，权重越高。
- 没有报告时显示"还没有评分，完成一次正式模拟后显示"；只有一份报告时显示"初始评估"；证据不足的维度不显示分数。
- 每个维度都可以展开查看依据，并跳转到对应的报告。

## 3. 训练统计

| 指标             | 口径                                               |
| ---------------- | -------------------------------------------------- |
| 有效练习次数     | 已完成的面试，或实际训练时长达到 8 分钟的面试      |
| 累计有效时长     | 服务器记录的实际作答时长；暂停、离开页面的时间不算 |
| 本周有效训练天数 | 每周从周一开始；同一天练习多次只算一天             |
| 连续天数         | 按自然日计算；今天还没练时，从昨天开始往前数       |

**不计入**有效训练的行为：登录、打开成长中心、浏览报告、单独写笔记。

## 4. 最新复盘

展示最近一场面试的结论、优势和下一步入口：

| 情况               | 显示                                                     |
| ------------------ | -------------------------------------------------------- |
| 报告已经生成       | "查看完整报告"                                           |
| 有一场未完成的练习 | "继续练习"，恢复原来的题目、回答、提示、笔记、配置和计时 |
| 报告正在生成       | "报告正在生成，稍后刷新即可查看"                         |
| 还没有任何面试     | "完成一次模拟，建立你的准备基线"                         |

旁边还有"最近题目收藏"：最多显示 3 张待复习卡片，"查看全部"进入[题目收藏](题目收藏.md)。

## 5. 面试复盘记录

全部面试记录，按时间倒序排列。

- **筛选**：全部 / 有报告 / 待继续。
- **卡片主按钮**：按状态区分，不会让人猜能不能点：

| 状态               | 主按钮                                               |
| ------------------ | ---------------------------------------------------- |
| 报告已就绪         | 查看报告                                             |
| 练习进行中或已暂停 | 继续练习（回到原来那一场，不会新建面试，也不扣费）   |
| 正式模拟中途离开   | 自动开始生成报告，卡片显示"生成中"；正式模拟不能继续 |
| 生成中             | 没有可点的按钮                                       |
| 已完成但没有报告   | 查看报告状态（可以在报告页重新生成）                 |

- **删除**：需要二次确认，删除后报告和对话都无法恢复。
- 进入成长中心不会批量为历史面试生成报告。
