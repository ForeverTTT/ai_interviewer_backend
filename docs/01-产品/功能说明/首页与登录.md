# 首页与登录

> 状态：现行 · 最后核对：2026-10-01 · 通用规则：[通用规则 · 账户与登录](../通用规则.md#1-账户与登录) · 技术文档：[首页与登录](../../03-技术与架构/首页与登录.md)

## 落地页（`/`）

- **用户目标**：了解 FlowLab 能做什么，然后开始练习。
- **内容顺序**：首屏主视觉 → 院校 / 企业 Logo 滚动 → 使用流程 → 平台优势 → 技术能力 → 用户评价滚动 → 页尾行动按钮。
- **主按钮去向**：未登录时跳转到登录页；已登录时直接进入面试配置页。
- **布局**：官网式顶栏，可以切换语言和主题；没有侧栏。

## 登录（`/login`）

- **方式**：使用 Google 账号登录、使用 LinkedIn 账号登录、使用邮箱登录。
- **邮箱登录**：点击后在卡片里展开表单，可以在「登录 / 注册 / 忘记密码」之间切换；密码至少 8 位。注册后需要点开邮件里的确认链接，确认后经登录回调进入面试配置页。
- **登录后去向**：如果是访问受保护页面时被拦下来的，登录后回到原页面；直接打开登录页的，登录后进入面试配置页。
- **已登录用户**访问登录页时会被直接带走，不会重复登录。
- 页面上写明"登录即代表同意我们的服务条款和隐私政策"。

## 登录回调（`/auth/callback`）

第三方授权完成后回到这个页面，用户只会看到"正在完成登录… / 登录成功！正在跳转…"。

| 情况 | 表现 |
|---|---|
| 成功 | 进入面试配置页 |
| 失败或超时 | 错误信息留在页面上，提供"立即返回"登录页的按钮；不会自动清除登录状态 |
| 重复打开同一个回调链接 | 授权码只能使用一次，第二次会失败，需要重新登录 |

## 重置密码（`/auth/reset-password`）

在登录页点「忘记密码？」并填写邮箱后，系统发送重置邮件。为避免暴露哪些邮箱注册过，无论邮箱是否存在，页面都提示「如果已注册，重置链接已经发出」。点开邮件里的链接后在这个页面设置新密码（输入两次），保存后进入面试配置页。链接无效或过期时提示回到登录页重新申请。

## 边界情况

- 从受保护页面被拦截后，如果走的是第三方授权，回调完成后进入的是**面试配置页**，而不是原来的页面（只有在登录页直接完成登录时才会回到原页面）。
