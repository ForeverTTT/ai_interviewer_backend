# 通用规则

> 状态：现行 · 最后核对：2026-10-01 · 对应技术文档：[账户与计费](../03-技术与架构/通用机制/账户与计费.md)、[前端架构](../03-技术与架构/通用机制/前端架构README.md)

所有模块都要遵守的产品规则。各功能说明只写与本文不同的部分。

## 1. 账户与登录

- **登录方式**：Google 或 LinkedIn 账号，不支持邮箱密码注册。登录即代表同意服务条款和隐私政策。
- **新用户**：第一次登录自动建档，赠送 **1000 能量值**。
- **无需登录的页面**：首页、登录页、面经库（只能浏览，不能发布）。其余页面未登录时跳转到登录页。
- **会话保持**：登录状态保存在浏览器中，并会自动续期。接口偶尔返回未授权时，系统会先自动刷新登录状态再重试；只有确认登录确实失效，才会退出登录，避免用户被无故踢下线。
- **退出登录**：在侧栏底部。

## 2. 能量值

能量值是使用 AI 功能的额度单位，侧栏底部常驻显示当前余额。

### 2.1 消耗

| 功能 | 消耗 | 什么时候扣 |
|---|---:|---|
| 开始一场模拟面试（练习或正式） | 300 | 创建面试时扣一次。面试过程中的对话、语音、报告生成和报告翻译都不再扣 |
| 从收藏题或推荐题开始针对性练习 | 300 | 同上 |
| 简历诊断 | 200 | 诊断成功并保存后才扣 |
| 简历解析（AI 填入结构化资料） | 50 | 解析成功后才扣 |
| 按 JD 优化简历 | 100 | 生成成功后才扣 |
| 生成求职信 | 100 | 生成成功后才扣 |
| 优势测试出报告 | 100 | 报告保存后才扣 |

原则：**AI 失败不扣费。** 只有创建面试是在开始时扣，并且网络重试不会重复扣。

### 2.2 获得

| 方式 | 数量 | 规则 |
|---|---:|---|
| 注册 | +1000 | 一次性 |
| 分享面经 | +200 | 每人每天最多分享 1 篇；删除自己的面经会扣回 200 |

目前**没有充值**。"获取更多能量"按钮打开的是引导弹窗：分享面经，或关注小红书。

### 2.3 余额不足

- 余额不足时提示"能量值不足"，操作不会执行，也不会扣费。面试配置页会在提交前就检查余额；其他功能由服务端拒绝后再提示。
- 弹窗或提示中会引导用户前往个人资料页了解获取方式，或者去面经库分享面经。

## 3. 多语言

有两个**彼此独立**的语言设置：

| 设置 | 可选值 | 影响 | 在哪里改 |
|---|---|---|---|
| 界面语言 | 中文、English、Deutsch | 按钮、标签、提示；报告和简历诊断会按界面语言显示 | 侧栏或顶栏的语言切换 |
| 面试语言 | English、Deutsch、中文 | AI 提问、面试官语音、语音识别 | 每场面试配置时选择，创建后不能修改 |

规则：

- 第一次访问时跟随浏览器语言，用户选择后记住。不支持的语言回退到**中文**。
- 可以用中文界面进行德语面试。
- 报告、简历诊断切换界面语言时会自动翻译，不重新分析，也不扣费。
- 新增界面文案必须同时提供三种语言。

## 4. 页面状态

所有页面按以下统一方式处理各种状态：

| 状态 | 表现 |
|---|---|
| 加载中 | 显示加载提示，不显示空白页 |
| 空状态 | 说明为什么是空的，并给出一个明确的下一步按钮（例如"开始第一次面试"） |
| 操作失败 | 就近显示可以理解的错误原因，提供重试；已有内容不会因此丢失 |
| 未登录 / 登录失效 | 需要登录的页面跳转到登录页；正在填写的表单提示"登录状态已失效，请重新登录" |
| 能量值不足 | 见 2.3 |
| 正在生成（报告、诊断） | 告知大约需要多久；报告生成时用户可以先离开，完成后会出现在成长中心 |
| 删除 | 一律需要二次确认，并说明删除后不可恢复 |

文件上传统一规则：只接受 PDF；面试配置、简历优化、个人资料页的简历 PDF 上限 12 MB；扫描件（没有可选文本）、加密 PDF、损坏文件分别给出明确提示。头像图片上限 2 MB。

## 5. 主题与品牌

- **产品名**：LandIt（见[产品概览 · 名称约定](产品概览.md#名称约定)）。
- **浅色 / 深色主题**：可以切换，选择会被记住；面试房间有单独的主题开关。
- **布局**：登录前是官网式顶栏布局；登录后是左侧侧栏工作台，侧栏分为"面试训练 / 求职材料 / 社区"三组，可以折叠，手机上是抽屉。面试房间全屏显示，不显示侧栏。
- **Cookie 提示**：首次访问时显示，可以全部接受、自定义或拒绝。
