# 面试报告

> 状态：现行 · 最后核对：2026-10-01 · 产品说明：[面试报告](../01-产品/功能说明/面试报告.md)
> 代码：`backend/src/routes/interviews.js`（`/finalize`、`/report/translate`；报告 Prompt 是文件内的 `REPORT_JSON_SYSTEM`，不是 `data/prompts/feedback_agent.md`）、`backend/src/lib/interviewFinalize.js`、`frontend/src/pages/InterviewReportPage.jsx`

面试结束后，`finalize` 根据已持久化的对话和作答生成结构化报告，保存在 `interviews.report_json`。报告中的五维准备度会被成长中心汇总，见[成长中心 · 职场胜算](成长中心.md#2-职场胜算五维准备度汇总)。

## 1. 生成与结束流程


### 1.1 Finalize API

`POST /api/interviews/:id/finalize`：

1. 校验面试归属和请求输入；
2. 如果 `status=completed` 且已有 `report_json`，直接复用结果；
3. 调用 `claim_interview_finalize` 原子取得 120 秒生成锁；
4. 其他并发请求收到 `202 { processing: true }`；
5. 取得锁的请求读取规范化 attempts 和持久 transcript；
6. Gemini 生成结构化报告；
7. 解析、规范化并保存 `report_json`；
8. 更新 `status=completed`、`finalize_status=completed` 和模型/耗时信息；
9. 失败时保存失败 stage、摘要和 retryable 标记。

报告使用独立模型调用预算：单模型默认等待 30 秒，总预算 90 秒。保持 `GEMINI_MODEL` 主模型，失败后默认依次尝试 `gemini-3.1-flash-lite`、`gemini-3.5-flash-lite`；每个候选最多请求一次，模型间按约 1、2 秒退避并加入随机抖动。实际尝试和等待均受总预算约束；不会因为增加备用模型延长到生成锁之外。配置见[环境变量](../02-开发指南/环境变量.md#gemini-模型)。练习出题仍保持 15 秒总预算。

失败原因按实际错误分类：`gemini_quota_exhausted` 仅表示配额或限流；503 等临时故障记作 `gemini_unavailable`；单模型/请求超时记作 `gemini_model_timeout`；模型不存在与网络故障分别记录。每次模型调用还在 Cloud Logging 输出 `gemini_text_attempt_completed` 或 `gemini_text_attempt_failed`，包含请求/面试 ID、模型、耗时、单次与总预算、失败类型和脱敏错误摘要，不记录 prompt 或对话。

练习报告强调首次与最新回答差异、提示使用和能力成长；正式报告只在结束后评价整场表现。

### 1.2 当前异步边界

当前实现有“并发请求返回 202 + 状态轮询”，但没有独立持久任务队列：

- 首次取得 finalize 锁的 HTTP 请求仍在请求生命周期内调用 Gemini 并保存报告；
- 并发或重复请求在 processing 期间返回 202；
- 前端当前会等待首次响应，收到 202 时最多轮询约 120 秒，与生成锁时长对应；
- 若产品要求用户点击结束后立即离开页面，仍应新增持久 job/queue 或 Cloud Tasks/后台 worker，不能仅靠
  前端 fire-and-forget 假装异步。

这是一项当前技术限制，而不是已完成能力。

### 1.3 报告翻译

`POST /api/interviews/:id/report/translate` 只翻译报告分析块，并按 UI locale 缓存结果；基础报告仍保留
原始面试语言语义。


## 2. 报告结构中的准备度

- 报告 Schema 新增 `careerReadiness.version=1` 和 `nextPracticeTask`。五个固定维度为：技术能力、经历与证据深度、结构化表达、沟通与协作、面试策略与岗位匹配。
- 每个有分数的维度都必须带 `interviewId + questionIndex + excerpt` 证据，以及标题、原因、预计时长和原题组成的可执行动作；无匹配证据时维度状态为 `insufficient`，不从资料完整度或练习次数猜分。

## 3. 前端行为

| 行为 | 实现 |
|---|---|
| 自动翻译 | 页面加载后，如果界面语言与 `report_ui_locale`（没有时用面试语言）不同，就调用 `/report/translate`，结果按语言缓存在服务端 |
| 重新生成 | 只在没有报告且存在已保存对话时显示按钮，调用 `/finalize` 并传 `forceRegenerate: true`，不扣费 |
| 逐题收藏 | 每张题卡的"收藏本题"调用 `POST /api/growth-center/collections`，再点一次取消收藏，见[题目收藏](题目收藏.md) |
| 下一道推荐题 | 读取 `report_json.nextPracticeTask`；"开始针对练习"先幂等收藏该题，再调用 `/collections/:id/practice` 新建练习（300） |
| 两种复习视图 | 单题卡（`QaDeck` card 模式）和所有题总览 |
| 历史格式 | 旧的 Markdown 报告（`report_markdown`）转换成卡片排版显示 |
