# 题目收藏

> 状态：现行 · 最后核对：2026-10-01 · 产品说明：[题目收藏](../01-产品/功能说明/题目收藏.md)
> 代码：`backend/src/routes/growthCenter.js`（`/collections*`）、`backend/src/lib/growthCenter.js`、`frontend/src/pages/NotesPage.jsx`、`frontend/src/pages/InterviewReportPage.jsx`（逐题收藏）

题目收藏的数据和接口属于成长中心（`/api/growth-center/collections*`），界面是独立页面 `/notes`。成长中心首屏的"最近题目收藏"见[成长中心](成长中心.md)。

## 1. 数据

表 `interview_question_collections`，每张卡片一行，字段见[数据库参考 · 成长中心](../04-参考/数据库.md#成长中心)。

| 字段 | 说明 |
|---|---|
| `origin_key` | 来源题目的唯一标识，与 `user_id` 组成唯一约束，所以同一原题重复收藏是幂等的 |
| `source` | `practice`（练习笔记）或 `report`（报告逐题收藏） |
| `question_text`、`answer_text`、`feedback_snapshot` | 收藏时的快照，之后不随原面试变化 |
| `personal_note`、`tags`、`is_pinned`、`review_status` | 用户可以修改的字段 |
| `interview_id`、`question_id` | 指向来源；来源被删除时置空（`on delete set null`），卡片保留 |

## 2. 实现要点

- 迁移 `20260826193000_growth_center_phase_2_3.sql` 新增 `interview_question_collections`。卡片统一保存原题、用户回答、反馈快照、职位、语言、面试官类型、来源、私人笔记、标签、置顶和复习状态；`origin_key + user_id` 保证同一原题幂等收藏。
- 旧 `interview_notes` 迁移为练习来源卡片的可选 `personal_note`。保存练习笔记或更新该题答案时，会同步统一卡片；笔记本身不产生有效训练事件。
- 报告页只提供逐题收藏，不提供整份报告收藏或整份报告自由笔记。`POST /api/growth-center/collections` 从用户拥有的 Session 和报告中重新提取权威快照，不信任前端上传的题目、回答或反馈文本。
- `/notes` 是完整收藏库，提供全文搜索、职位/面试官/来源/标签/日期/复习状态筛选、置顶、复习、私人笔记、取消收藏、返回原内容和“再练一次”。
- `POST /api/growth-center/collections/:id/practice` 创建新的练习 Session，并把收藏原题作为首个针对性问题。它不会恢复或改写来源 Session。

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/growth-center/collections` | 搜索和筛选 |
| POST | `/api/growth-center/collections` | 从练习题或报告题收藏，服务端重新提取快照 |
| PATCH | `/api/growth-center/collections/:id` | 更新笔记、标签、置顶、复习状态 |
| DELETE | `/api/growth-center/collections/:id` | 取消收藏 |
| POST | `/api/growth-center/collections/:id/practice` | 新建针对性练习（10 分钟、Medium），消耗 300；用 Service Role 调用 `create_interview_session` |

完整参数见 [API 参考 · 成长中心](../04-参考/API.md#成长中心-apigrowth-center)。

## 4. 与有效训练的关系

写笔记、修改卡片、复习都**不会**产生 `interview_training_events`，不计入有效训练。口径见[成长中心 · 统计口径](成长中心.md#32-统计口径)。
