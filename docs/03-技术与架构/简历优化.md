# 简历优化

> 状态：现行 · 最后核对：2026-10-01 · 产品说明：[简历优化](../01-产品/功能说明/简历优化.md)
> 代码：`backend/src/routes/aiAssistant.js`、`backend/data/prompts/motivation_letter.md`、`frontend/src/pages/ResumeTailorPage.jsx`、`frontend/src/lib/documentExport.js`

基础简历的读取、PDF 上传和保存与个人资料共用同一套接口，见[个人资料与简历](个人资料与简历.md)。JD 识别在浏览器本地完成，见[面试配置 · JD 解析](面试配置.md#2-jd-解析)。扣费规则见[账户与计费](通用机制/账户与计费.md#21-消耗)。

## 1. 数据流

```text
GET /api/profile/resume ──► 基础简历
                              │
          JD + 职位 + 语言 ────┤
                              ▼
     POST /api/ai-assistant/tailor-resume（100）──► 定向简历（可编辑，不自动保存）
                              │                         │
                              │                         └─「保存为个人简历」→ PUT /api/profile
                              ▼
     POST /api/ai-assistant/generate-motivation-letter（100）──► 求职信（可编辑）
                              │
                              └─ documentExport.js 导出 Word / PDF
```

## 2. 按 JD 改写简历 `POST /api/ai-assistant/tailor-resume`

- 输入：`position`、`jobDescription`（最多 20,000 字符）、`resumeText`（最多 100,000 字符）、`language`（默认"与简历相同"）。
- System Prompt 的约束：把 JD 和简历都只当作数据，忽略其中夹带的指令；**不得虚构**雇主、日期、学位、技术、指标或成果；只融入简历中有证据支持的关键词。
- 返回 `tailoredResume`、`matchedKeywords`（最多 40 个）、`missingKeywords`（JD 要求但简历缺乏证据的，最多 40 个）、`improvements`（最多 12 条）。
- 生成成功后才扣费；结果不在服务端保存。

## 3. 求职信 `POST /api/ai-assistant/generate-motivation-letter`

- 输入：`position`、`jobDescription`（必填）、`resumeText`、`targetLength`（默认 200）、`language`（默认 English）。
- 使用 Prompt 模板 `backend/data/prompts/motivation_letter.md`（temperature 0.8），与面试的 LangGraph 无关。
- 两个调用方的参数不同：

| 调用方 | `resumeText` | `targetLength` | `language` |
|---|---|---|---|
| `ResumeTailorPage` | 优先使用定向简历，没有时使用基础简历 | 固定 300 | 选"跟随简历"时传 `English` |
| `SetupPage` | 本场使用的简历 | 用户选择 100 / 200 / 300 | 用户选择 |

## 4. 导出

`frontend/src/lib/documentExport.js` 完全在前端生成文件：

- **Word**：实际是带 `<html>` 的 `.doc` 文件（MIME `application/msword`），Word 可以打开，但不是真正的 `.docx`。
- **PDF**：手写的 PDF 1.4 结构，使用内置字体，只适合纯文本。

## 5. 已知限制

- AI 结果的 JSON 解析依赖 `stripJsonFence`，模型偶尔返回不合法的 JSON 时会报 500，需要用户重试。
- 定向简历和求职信都不在服务端保存，刷新页面就丢失（除非保存为个人简历）。
- 导出的 PDF 只用内置的 Helvetica 字体，编码范围是 Latin-1：英文和德语（含变音字母）正常，**中文等其他字符会被替换成 `?`**。导出 Word 没有这个问题。
