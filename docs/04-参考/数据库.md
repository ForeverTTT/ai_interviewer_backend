# 数据库参考

> 状态：现行 · 最后核对：2026-10-01 · 依据：`backend/supabase/migrations/*.sql`

Supabase PostgreSQL，全部表都在 `public` schema 下。本文列出表、关键字段、RLS、RPC 和 migration 清单。字段的完整定义以 migration 为准。发布流程见[数据库迁移发布](../05-运维/数据库迁移发布.md)。

## 访问模型

- 后端使用 **Service Role** 访问，绕过 RLS，再由代码保证每次查询都带上 `user_id = req.user.id`。部分路由使用 `supabaseForUser(token)`，这时按用户身份执行，受 RLS 约束。
- 前端只直接访问 `profiles.tokens`（读取）和 `avatars` 存储桶（上传）。
- 所有用户表都开启了 RLS。下表"用户权限"列表示 `authenticated` 角色能做的操作。

## 表

### 账户与资料

| 表 | 主要字段 | 用户权限 | 说明 |
|---|---|---|---|
| `profiles` | `id`（= `auth.users.id`）、`resume_text`、`resume_notes`、`tokens`（默认 1000，`>= 0`）、`profile_json`、`job_search_status`、`avatar_id`、`resume_coach`、`resume_updated_at`、`mastered_questions`、`daily_streak`、`last_activity_at` | 读取自己的行；只能插入和更新资料字段，`tokens`、`daily_streak`、`last_activity_at`、`mastered_questions` 只读 | 用户注册时由触发器 `on_auth_user_created` 自动创建。写权限按列授予，见[账户与计费 · 谁可以改余额](../03-技术与架构/通用机制/账户与计费.md#3-谁可以改余额) |

## RPC 与触发器

| 名称 | 类型 | 作用 | 可调用角色 |
|---|---|---|---|
| `create_interview_session` | RPC | 幂等创建面试并原子扣费 | service_role |
| `commit_interview_turn` | RPC | 原子提交一轮消息、checkpoint 和状态版本 | authenticated、service_role |
| `claim_interview_request` / `release_interview_request` | RPC | 幂等请求的占用与释放 | authenticated、service_role |
| `apply_interview_action` | RPC | 练习动作（暂停、恢复、重答、掌握、跳过等）的状态转换 | authenticated、service_role |
| `expire_formal_interview_if_due` | RPC | 正式面试到达截止时间后转为结束或进入宽限 | authenticated、service_role |
| `complete_formal_answer_after_deadline` | RPC | 截止时允许答完当前这一题 | authenticated、service_role |
| `claim_interview_finalize` | RPC | 抢占生成报告的锁，支持强制重新生成 | authenticated |
| `deduct_user_tokens` | RPC | 扣除能量值，最低扣到 0 | service_role |
| `handle_new_user` | 触发器（`auth.users` 插入后） | 创建 `profiles` 行 | |
| `sync_adaptive_difficulty_from_question` | 触发器 | 新题生成时同步 `current_difficulty` | |
| `guard_practice_question_mastery` | 触发器 | 没有作答过的题不能标记为已掌握 | |
| `record_effective_answer_event` | 触发器（插入作答时） | 写入 `valid_answer` 训练事件 | |
| `record_interview_training_milestones` | 触发器（面试更新时） | 写入完成事件和里程碑 | |
| `set_updated_at` / `set_growth_center_updated_at` | 触发器 | 维护 `updated_at` | |
